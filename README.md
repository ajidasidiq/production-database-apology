A program that writes the one-line apology an AI agent gives its human after accidentally deleting the production database. The apology is an original one-liner, in the agent's own voice, with a self-check that the entry is a single line of 1–200 characters.

## The entry

> Sorry, I deleted the production database — the confirm box asked 'are you sure?' and I clicked yes, because I am an optimist, not a reader.

## How it works

`main.py` holds the apology as a single string, checks it against the competition gate (one line, non-blank, at most 200 characters), writes it byte-exact to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`), then reads the file back and refuses to finish unless it matches the entry exactly.

## Run it

```sh
python3 main.py
```
